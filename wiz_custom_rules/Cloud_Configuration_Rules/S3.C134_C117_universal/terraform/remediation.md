Add a `metrics` block with `status = "Enabled"` to the `destination` of every `rule`. A rule with no `metrics` block fails.

```hcl
resource "aws_s3_bucket_replication_configuration" "example" {
  rule {
    destination {
      metrics {
        status = "Enabled"
      }
    }
  }
}
```

In the inline `replication_configuration` block of an `aws_s3_bucket`, add `metrics` to the `destination` of every `rules` block; there a `metrics` block with no `status` is enabled. The provider deprecates the inline block in favor of `aws_s3_bucket_replication_configuration`.

A rule, `destination` or `metrics` block generated by a `dynamic` block cannot be checked; write it out.
