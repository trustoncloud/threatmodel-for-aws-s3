For each bucket in `worm_buckets`, enable Object Lock and set its default retention in an `aws_s3_bucket_object_lock_configuration`, with the bucket's listed `mode` and `days` of at least its `min_days` (or `years`, a year counting 365 days). The configuration also enables Object Lock on an existing bucket once versioning is on, and it cannot be turned off afterwards. The inline `object_lock_configuration` block of `aws_s3_bucket` is deprecated; do not set both for one bucket.

```hcl
resource "aws_s3_bucket" "example" {
  bucket              = "<bucket-name>"
  object_lock_enabled = true
}

resource "aws_s3_bucket_object_lock_configuration" "example" {
  bucket = aws_s3_bucket.example.id

  rule {
    default_retention {
      mode = "COMPLIANCE"
      days = 365
    }
  }
}
```

Use the bucket's listed `mode` in place of `COMPLIANCE` and its `min_days` or more in place of `365`. Replace `<bucket-name>` with the bucket in the finding.

A default retention generated by a `dynamic` block cannot be read and is reported; write the block out.
