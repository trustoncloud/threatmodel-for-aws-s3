Set `blocked_encryption_types` in each bucket's `aws_s3_bucket_server_side_encryption_configuration`: `["NONE"]` for a bucket in `buckets_requiring_ssec`, and `["SSE-C"]` for every other bucket. An unset value is reported, since S3's default then depends on the bucket's age and the account's SSE-C history. The argument needs hashicorp/aws provider 6.x.

```hcl
resource "aws_s3_bucket_server_side_encryption_configuration" "example" {
  bucket = aws_s3_bucket.example.id

  rule {
    blocked_encryption_types = ["SSE-C"]
  }
}
```

A `rule` generated by a `dynamic` block hides `blocked_encryption_types` and is reported; write the rule out.
