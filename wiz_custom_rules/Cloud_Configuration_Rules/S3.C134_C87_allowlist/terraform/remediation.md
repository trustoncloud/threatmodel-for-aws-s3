Remove the `aws_s3_bucket_replication_configuration` of a bucket that is not authorized, or the inline `replication_configuration` block of its `aws_s3_bucket`, or set each rule to `status = "Disabled"`. If the bucket is approved, add its name to `authorized_replications` instead, and to the same list in S3.C88.

```hcl
resource "aws_s3_bucket_replication_configuration" "example" {
  bucket = aws_s3_bucket.example.id

  rule {
    status = "Disabled"
  }
}
```

The source bucket is read from `bucket`, as a literal name or a reference to an `aws_s3_bucket` with a literal `bucket`. An inline block belongs to the `aws_s3_bucket` that declares it, and its rules are `rules` blocks. A name known only at apply is left to the cloud check.

Replication rules generated by a `dynamic` block cannot be read; write each rule out, or add the bucket to `authorized_replications` once approved.
