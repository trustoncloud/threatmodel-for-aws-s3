Declare an `aws_s3_bucket_abac` that enables ABAC for each bucket in `authorized_abac_buckets`, in the same file as the bucket, and set `status = "Disabled"` (or declare none) for every other bucket. An authorized bucket with no `aws_s3_bucket_abac` keeps ABAC off and is reported. A bucket whose name the source scan cannot resolve to a literal is not judged. The resource needs hashicorp/aws provider 6.x.

```hcl
resource "aws_s3_bucket_abac" "example" {
  bucket = aws_s3_bucket.example.bucket

  abac_status {
    status = "Enabled"
  }
}
```

An `abac_status` generated by a `dynamic` block cannot be read and is reported whatever the bucket, even one whose name is not resolved; write the block out.
