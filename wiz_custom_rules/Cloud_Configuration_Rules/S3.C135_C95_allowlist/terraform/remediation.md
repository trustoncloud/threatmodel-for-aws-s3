Point every `topic`, `queue` and `lambda_function` block at an ARN listed in `authorized_notification_receivers`, remove the block, or add the receiver there once approved. Set `eventbridge = true` only for a bucket listed in `eventbridge_buckets`, or add the bucket there once approved; that approval does not check where EventBridge rules forward the events.

```hcl
resource "aws_s3_bucket_notification" "example" {
  bucket      = "<bucket-name>"
  eventbridge = false

  topic {
    topic_arn = "arn:aws:sns:<region>:<account-id>:<topic-name>"
  }

  queue {
    queue_arn = "arn:aws:sqs:<region>:<account-id>:<queue-name>"
  }

  lambda_function {
    lambda_function_arn = "arn:aws:lambda:<region>:<account-id>:function:<function-name>"
  }
}
```

ARNs and bucket names are compared exactly as written. A receiver given as a reference to another resource, or a bucket whose name is known only at apply, is not compared here; the cloud check judges it once deployed.

A `topic`, `queue` or `lambda_function` block generated by a `dynamic` block cannot be compared and is reported; write each receiver out.
