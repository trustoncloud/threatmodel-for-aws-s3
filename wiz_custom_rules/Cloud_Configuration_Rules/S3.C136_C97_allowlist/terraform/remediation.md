Point `destination.bucket.bucket_arn` at a bucket listed in `authorized_inventory_destinations`, remove the `aws_s3_bucket_inventory`, or add the destination there once approved. Setting `enabled = false` does not clear the finding.

```hcl
resource "aws_s3_bucket_inventory" "example" {
  destination {
    bucket {
      bucket_arn = "arn:aws:s3:::<inventory-bucket>"
    }
  }
}
```

The ARN is compared exactly as written. A destination given as a reference to another resource is known only at apply and is not compared here; the cloud check judges it once deployed.

A `destination` or `bucket` block generated by a `dynamic` block cannot be compared and is reported; write it out.
